# Family 02 · Valves

Implemented from the Family 02 revision 04 design handoff and the **Family 02 approved amendment** in Family 03 revision 03. The amendment supersedes the earlier foot-valve proposal and the request for another geometry approval. The two review forms are labeled with their respective statuses. The drawings describe schematic equipment and connections. Equipment dimensions, flow capacity, actuator suitability and project compliance need separate engineering input.

## Drawing and state API

```js
import { composeValve, placeOperatingValve, placeSymbol } from "../src/library.mjs";

const config = {
  bodyId: "valve-ball",
  tag: "BV-201",
  normalPosition: "open",
  operatingPosition: { position: "closed", openingPercent: 0 },
  failPosition: "last",
  failEvent: "loss of power",
  actuator: { type: "motor", stemLength: 9 },
  endConnections: { in: { type: "flanged" } },
};
const design = composeValve(config, { x: 120, y: 80, q: 1, s: 1.5 });
const operating = placeOperatingValve(config, { x: 120, y: 80, q: 1, s: 1.5 });
const nrv = placeSymbol("valve-check", { x: 240, y: 80, q: 2 });
```

- `composeValve` defaults to the design view. `placeOperatingValve` lays out an operating snapshot from the same configuration. The host can rerender as readings change. Use `render(shapes, { profile: "screen" | "print" })` independently of the drawing view. The static identity glyph stays fixed. Travel labels describe valve travel only.
- Normal position supports `open`, `closed`, `partial` and `unknown`. Operating position accepts the same strings with an optional travel percentage from 0 to 100. Travel must agree with a known reported position. Failure position supports `open`, `closed`, `last`, `unknown` and `not-applicable` with a separate optional failure event. `null` or omitted means no value supplied, or inapplicable on a passive valve. `unknown` records that the position is explicitly unknown. The unfilled isolation glyph is qualified by a label when state is unavailable. `NO` means normally open, `NC` normally closed, `FO` fail open, `FC` fail closed and `FLP` fail at last position. Failure labels describe the configured response, independent of current travel.
- Check, foot, relief and air bodies use passive semantics. Three-way valves use explicit `activePortPairs`. An empty array specifies no active routes and omission leaves routes unspecified. The design geometry stays fixed. Operating snapshots label the reported pairs without highlighting or inferring an internal bore. A diverter can record fail-last or unknown failure behavior. A specific fail route would need its own port-pair model. The angle valve and pressure-reducing valve accept explicit state annotations without isolation fill.
- `byId[id].draw({ closed })` remains a raw local-geometry entry point with the original Boolean rendering convention. `placeSymbol(id, at, { closed })` keeps the Boolean rendering shorthand with small-size fallback. It leaves authoritative state metadata unset. Callers that need to distinguish unspecified normal state from a hollow open glyph should use `composeValve`.
- `processPorts` include stable IDs, points, outward normals, roles and end treatments. The legacy `ports` array projects process terminal coordinates in the same order. `connectivity` describes schematic terminal groupings. It carries no hydraulic state. `interfaces` separately holds environmental boundaries. `permittedFlow` points to the transformed endpoints for the NRV and foot valve, or an explicitly specified direction for a bidirectional two-port body. Pressure reduction uses ordered inlet/outlet roles and does not imply backflow prevention.
- `endConnections` accepts `plain` and the Family 01 two-plate `flanged` grammar, independently per pipe terminal. Flanges extend outward and return the new route endpoint. `bodyPoint` records the original endpoint. Mounts, heads and sensing attachments are separate from process terminals. Attachments to environmental interfaces are rejected.
- Family 03 provides the head, stem and mount implementation and preserves the earlier `actuator.type` values. See [Family 03](family-03.md) for the additional heads, operator identifiers and spring callout. Pinch, passive and pressure-reducing bodies have no generic operator mount. The float preset defaults to a gate-like body. Use `actuator: { type: "float" }` for another mountable body and supply the known float behavior explicitly.
- Labels use drawing-space anchors with upright text. The automatic layout uses space below the symbol or to its right when a lower terminal would cross the label. Supply a drawing-space `labelAnchor: [x, y]` for crowded routes. `bounds` encloses body and attachment geometry. An optional `measureText(text, font, align)` callback using the Family 01 ink-box convention returns `labelBounds` separately.

## Geometry and review decisions

- The 14 × 10 check triangle and 12.4-unit stop bar meet at the outlet. Family 04 can reuse the approved local shapes through `byId["valve-check"].draw({})`. Earlier manual routes from `[-8, 0]` and `[6, 0]` must use the new returned ports. The repository's inlet works drawing has no check placement. Its rebuild is byte-identical.
- The foot valve rotates that same triangle and bar upward. The outlet sits at `[0, -16]` and the screened boundary at `[0, 19]`. Only the outlet takes a pipe connection. The rotated triangle serializes its base vertices in reverse order from the handoff's description of the derivative. Its segment geometry is identical.
- The isolation bowtie uses two explicit triangles. Transparent SVG masks clear the identity marks on filled bodies and keep the same marks legible in hollow bodies and fallbacks. The needle clears all three strokes with a 3.4-unit round knockout. The pinch sleeve prototype uses opposed inward chevrons to communicate compression inside a waisted outline. Closed fill uses a transparent knockout to keep the chevrons visible. The knife keeps its projecting straight blade, which carries its closed fill. The fixture tests both identities at 0.65×. The pinch mark is a schematic interpretation of ProjectMaterials p. 5 and Edraw's valve legend.

- For a specified butterfly design closure, `composeValve`, typed `placeSymbol`, the generated legend and catalogue use the same diagonal disc and hollow centre as normal open, with an explicit NC for closed. Slide 21 of *Art of the P&ID* supports explicit NC. The small dot stays available as a closure cue in the legacy Boolean entry points at nominal size and in the operating view. Operating labels report actual position and supplied travel. For a nominal one-pixel stroke, fill thresholds are 1.25× for globe, ball, plug, needle and pinch, 1.5× for legacy/operating butterfly, and 1× for knife. Supply `renderScale` for the intended display reduction or `closedStyle: "label"` for the unfilled NC or CLOSED fallback. Extremely small drawings still require a legible output size for the identity glyph and text. Print uses full ink and the same geometry thresholds.
- The explicit pressure-reducing assembly routes the hydraulic impulse from a marked downstream tap at `[18, 0]` to the regulator head at `[0, -15]`. A plain outlet meets the pipe at the tap. A flanged outlet extends beyond it. Switch representations by rerouting to the returned process ports. Compact uses `[-8, 0]` and `[8, 0]`. Its **Pressure reducing** identification is included in library placement, composition, raw drawing and catalogue output, and in the legend name. Use `representation: "downstream-sensing"` when the sensing location matters. Supply setpoint as `{ value, units }` when a setting is known. The shared [Family 01 hydraulic grammar](family-01.md#routed-lines) uses repeating hooks where they fit and short dashes for compact runs. The explicit assembly adds a Hydraulic impulse caption when the dash fallback is used. The tap and receiver remain sensing points, with the pipe face returned separately through the process port API.
- The air combination arrows show air exchange. Metadata separately identifies the large air/vacuum and small pressurized-release functions. The float lever and tank example are schematic. The pinch sleeve and butterfly mark do not encode a measured aperture. These fixtures leave equipment selection, dimensions and installation details open.

## Verification and provenance

Design approval and historical source citations are recorded separately in the catalogue. The public references below were inspected for specific uses and visual conventions. Exact geometry remains pending verification against the applicable project legend and licensed standard.

- **Sydney Water, P&ID 003, PDF p. 18, version 1 dated 13 October 2026.** The inline-assets legend shows open/closed variants, a separate float operator, and distinct foot, non-return, regulating and sustaining symbols. Several glyphs differ from these processvg drawings. [Utility specification](https://www.sydneywater.com.au/content/dam/sydneywater/documents/technical-specification-piping-and-instrumentation-diagrams.pdf#page=18)
- **Morro Bay WRF IFC, 00-I-001, PDF p. 86, May 2020.** The legend was rendered and inspected. It names needle, pinch, combination air, pressure reducing/sustaining and float-operated devices, distinguishes pressure sensing sides and hydraulic versus electric line conventions, and uses different pinch, combination-air and check glyphs. [IFC legend](https://morrobaywrf.com/wp-content/uploads/1a_Morro-Bay-WRF-IFC-Drawings-5-22-2020-City-PE-Stamped.pdf#page=86)
- **Brown and Caldwell Pahala, P-002, PDF p. 7.** Shows the older diagonal check with a separate direction arrow, NO/NC examples, needle/knife identities, a symbolic float lever and distinct reducing/back-pressure forms with pilot takeoffs. The historical citation remains associated with the older check. [Pahala project legend](https://www.epa.gov/system/files/documents/2021-08/pahala-wwtp-design-build-drawings-2021-07-23.pdf#page=7)
- **BIS.** The publication bulletin identifies IS 3232:2024 as the third revision and lists the end of the 1999 edition's concurrent period as 6 July 2024. The baseline retains historical symbol-number citations. The current clauses and exact glyphs were unavailable for verification. [BIS publication bulletin](https://www.services.bis.gov.in/tmp/weekly_bulletin_3_523.pdf)
- **Equipment function.** KSB corroborates the pump suction check and strainer; Cla-Val confirms downstream regulation and that float-based control can open or close on rising level; Val-Matic separates large-orifice air/vacuum and small-orifice pressurized release; AKO describes sleeve compression; Swagelok describes needle metering and design-dependent shutoff. These corroborate functional semantics. [KSB](https://www.ksb.com/en-global/centrifugal-pump-lexicon/article/foot-valve-1115490) · [Cla-Val reducing](https://www.cla-val.co.uk/product/cla-val-90-01-pressure-reducing-valve/) · [Cla-Val float](https://www.cla-val.com/fire-protection/level-control-valves) · [Val-Matic](https://www.valmatic.com/Portals/0/pdfs/ARCO-OM2-1_6-8in_SB_CAV.pdf) · [AKO](https://www.pinch-valves.com/wp-content/uploads/2013/04/VZ_Operating-Instructions_AKO-UK_2013-10-24.pdf) · [Swagelok](https://www.chicago.swagelok.com/resources/best-practices/valve-selection-best-practices)

## Reproducing the review

Run `npm run all` for the legend and review builds, Plotter's drawing-tree check and both suites of semantic tests. The ignored `review/family-02/` directory contains the standalone SVGs linked from the generated review page. Comparison sheet 07 shows reduced open and closed pinch, knife and butterfly, historical and revised butterfly display at nominal size, and regulator identification and short-run sensing. Run `npm run check:valve-layout` for Chromium label overlap and clipping checks, mask reference validation and computed print ink on the review sheets and two valve legends. Add `-- --include-family-01` to include both families and their legends. The screen review sheets can also be passed directly to the unmodified Plotter checker.

The upstream checker treats full-ink labels as an error even for the existing print profile; `scripts/check.py` waives that rule for print drawings only. Chromium validates the print fixture at its intended full ink. The upstream static exporter rejects processvg's existing theme stylesheet on both baseline and new drawings. Standalone SVGs render directly in Chromium and librsvg. The local PDF review uses Chromium print and Poppler raster inspection.
